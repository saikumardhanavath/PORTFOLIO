SAI KUMAR - DATA ANALYST PORTFOLIO

HOW TO OPEN
1. Extract this complete folder.
2. Keep index.html, assets/, and projects/ together.
3. Open index.html in Chrome or Edge.

NEW FEATURES
- Project filters: All / Power BI / Excel
- Expandable project case studies
- Dark / light mode (preference saved in the browser)
- Contact form and feedback form (both prepare an email; the visitor must press Send)
- Back-to-top button and hover animations

PROJECT FILES
Power BI .pbix files need Power BI Desktop. The .xlsx file needs Excel or a compatible spreadsheet app.
